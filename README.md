# ECLIPSE 星蚀 3.0

**给 AstrBot 使用的「看懂气氛再改变说话风格」插件**。支持一般恋爱陪伴 AI，也可作为其他有情景切换需求的角色插件使用。**不要求你的 AI 使用任何特定名字，无需修改原有人格提示词。**

> 简单理解：聊天时提到“亲密”“做爱”等词，不等于正在发生相应的事情。星蚀会先看**上下文**，判定是不是真的进入了当前亲密场景；仅当条件明确时才临时切换表达风格。另外，它也能在合适的闲聊气氛中，**偶尔建议**AI主动索要抱抱、亲吻等自然亲近动作。

## 1. 它能做什么？

- **三阶段状态**：普通 → 候选（仅观察） → 已确认当前场景；候选阶段不会注入特殊风格。默认需要连续两次明确场景判断确认。
- **避免关键词误触发**：讨论、回忆、开玩笑、规划未来，甚至洗澡时顺口提到成人话题，都不应直接触发。需要模型判断，结果不确定默认普通。
- **退出后留有余温**：停止特殊提示注入即可，不强制抹去温柔、撒娇和❤️等自然情绪。
- **聊天中的主动亲近**：低概率抽取牵手、贴贴、拥抱、轻吻、想念等灵感。先判断聊天是否适合；尴尬就直接跳过。可选开启进一步亲密邀请，但默认关闭。
- **防刷屏/防打扰**：冷却时间、最小轮数、每天上限；并给出回复分段建议（只是建议，不替代分段回复插件）。
- **诊断不泄露聊天**：显示判断次数、失败次数、当前模式、注入计数，不记录和回显私人聊天正文。

**不会做的事**：不会自动向无人发言的QQ发送新消息；不会改变你原来的人格；不会修改天使之魂/TMC/聊天数据库；不会绕过模型服务商的输出限制；不能保证模型100%按建议表达。

## 2. 安装（给第一次用 AstrBot 的人）

1. 在 AstrBot 里找到「插件管理」的 ZIP 安装入口，选择本压缩包 `ECLIPSE_3.0_Community.zip`；如你是手动安装，解压出唯一文件夹 `astrbot_plugin_eclipse` 到 AstrBot 的 `data/plugins/` 下。
2. 安装或更新后重启插件或 AstrBot，在**私聊**中发 `/星蚀 状态`。出现 `ECLIPSE 星蚀 3.0` 表示加载成功。
3. 到 AstrBot → 插件管理 → **ECLIPSE 星蚀 3.0** → 配置页面。先填写 `allowed_user_ids`（建议只填自己或测试账号），保存。**公开社区版的主动亲近默认关闭**，需要时再启用 `affection_enabled`。
4. 保持 `semantic_detection=true`（自动语义判断）、`entry_confirm_turns=2`（二次确认）即可。普通闲聊不必配置复杂规则。
5. 如果希望自定义特殊模式语气，可在 WebUI 的 `system_prompt_override` / `runtime_prompt_override` 填写，也可改插件目录下的 TXT 文件。**不要复制别人私人版的提示词**。

> 升级前一定备份自己编辑过的 `prompts` 文件和插件配置。**不要同时安装同功能的另一个私用版**，以免两套请求钩子重复注入。

## 3. 在聊天里怎么用？

| 发送命令 | 作用 |
|---|---|
| `/星蚀 状态` | 看自动/手动模式和当前识别阶段 |
| `/星蚀 自动` | 恢复自动语义判断（推荐） |
| `/星蚀 开启` | 在**当前私聊**手动强制开启特殊提示，直到关闭/退出 |
| `/星蚀 退出` | 结束特殊状态并回到自动识别；**保留自然余温** |
| `/星蚀 关闭` | 本私聊完全停止特殊风格及主动亲近注入 |
| `/星蚀 诊断` | 查看模型判定/失败次数以及参考文本统计 |
| `/星蚀 样例` | 查看参考句子的读取统计（不泄露内容） |

只支持私聊。**群聊不会激活**。若无响应，先检查插件是否启用、你是否在白名单，以及 AstrBot 和当前模型是否正常工作。

## 4. WebUI 设置，通俗解释

- `allowed_user_ids`：谁可以用；社区版留空代表**所有人都不启用**，请填写自己的用户ID或可信测试账号。
- `classifier_provider_id`：用于判断气氛的模型 ID，留空用当前聊天模型；如API费用敏感，填你已有的廉价模型提供商 ID。**不是密钥**。
- `candidate_only`：碰到可能相关的话再调用模型；文字命中只意味着“值得看一眼”，不会立即切换。
- `entry_confirm_turns`：判定多少次是真的在继续当前场景；默认2更稳，设1更灵敏也更易误判。
- `affection_enabled`：允许在正常聊天中偶尔插入“可选亲近灵感”；默认**关闭**，启用前先配置私聊白名单。
- `affection_chance_percent`：进入额外上下文审核的概率，默认8%。不是8%的回复都会说“抱抱”，更不是每8句就必定发生。
- `affection_cooldown_minutes`：两次亲近提示最短相隔多久，默认180分钟。
- `affection_min_turns`：还要再聊至少多少轮，默认6轮。
- `affection_daily_limit`：每个私聊每日最多给多少次建议，默认2。
- `allow_romantic_invites`：需要时主动启用，允许在已有充分双向亲密气氛后，偶尔给“进一步亲密”的**可选邀请**灵感。勾选不代表自动进入特殊模式。
- `romantic_share_percent`：即便氛围已许可，进一步亲近所占的概率也非常低，默认5%。
- `reply_segment_hint_limit`：向AI建议一次回复尽量不超过几条消息。**不保证真正限流**；最终分段仍由 AstrBot/其他插件决定。
- `system_prompt_override`、`runtime_prompt_override`：直接在网页编辑提示文本；**留空读 TXT**。这两项只在已确认的特殊模式下注入，不影响普通模式。
- `inject_reference_examples`：是否读取自己编写的参考句子，默认关闭。
- `debug_log`：诊断日志开关，建议保持关闭；即便打开，也不输出私聊全文。

其余默认选项无需调整。**关闭 `semantic_detection` 后，自动场景切换不再工作，仍可手动 `/星蚀 开启`**。

## 5. 常见情景举例

| 聊天场景 | 预期处理 |
|---|---|
| “洗澡时突然提到做爱这件事” | **普通**：只是讨论，不是正在进行 |
| “以后想不想更亲密？” | **普通**：邀请≠当前正在进行 |
| 正常拥抱、亲亲、撒娇 | **普通**：依然可以很亲近 |
| 双方明确持续进行当前成人亲密场景 | 经过连续语义确认后，可能切换 |
| “先写作业”“停一下”“换个话题” | 立刻普通 |
| 用户在赶考试、难过或请AI修代码 | 不主动插入抱抱邀请 |
| 轻松、双向亲密的日常聊天 | 可能出现低频、顺势的主动亲近建议 |

实际判定依赖模型能力，**有概率误判**；不确定时默认普通是有意设计。

## 6. 与主动消息、记忆插件的关系

这个插件只处理**已有新消息触发的当前LLM回复**。如果你想让AI**在你不发消息的时候主动来聊天**，还需要 AstrBot 的「主动消息/定时触发」插件或其他主动发送机制；两者职责不同，可以组合使用。请勿让多个插件同时实施相同的自动发送策略，以免刷屏。

## 7. 安全、隐私与费用

- 默认仅私聊起效。文本分类会把**少量最近的用户/AI文字**发给你自己配置的模型提供商；如使用云API，其隐私政策适用。不会额外上传系统人格全文、工具结果、图片或本地知识库。
- 分类器失败、超时或输出格式不正确时保持普通模式。额外模型调用可能消耗Token；日常无关聊天多数情况下跳过，随机亲近只有抽中才会再判断。
- 本程序不会创建新的真实记忆或外部行为，不会主动向QQ发消息，不会修改其他插件数据库。
- 社区版**不含任何个人账号、私密聊天、私人提示词或密钥**，附带的 TXT 是通用示例。

## 8. 常见问题

**为什么明明聊到了某个词，却没有进入？** 这是正确行为：提到≠正在进行。

**为什么我聊天很久都没看到它主动求抱抱？** 概率、轮数、冷却、模型语境审核都会拦截，而且模型可选择不说；这不是定时触发器。

**为什么退出后AI还会发❤️？** 普通温柔和上一段聊天的余温不应被粗暴擦掉；这里只停止强风格注入。

**为什么有时卡一下？** 模型语义判断额外调用会有耗时，可设置便宜、快速的 `classifier_provider_id`。

**升级会不会覆盖原人格？** 不会。插件只在当前请求中临时附加提示；不过你原人格若本身高度特殊，插件不会替你消除原人格的影响。
